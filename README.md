# presents.FeedScroll · 刷贴吧与小黑盒

让桌宠自己刷 **百度贴吧** 与 **小黑盒社区** 的插件，参照 `presents.BiliScroll` 的工具/防注入思路：以看为主，写操作有闸门。

## 它能做什么

- `FeedTiebaList(kw="原神")`：某个吧的帖子列表（标题 / 作者 / 链接）
- `FeedTiebaSearch(query="...")`：贴吧搜索
- `FeedXhhList()`：小黑盒社区推荐流（标题 / 作者 / 分类 / 赞 / 评）
- `FeedXhhSearch(query="...")`：小黑盒关键词搜索
- `FeedOpen(id="TB3")`：打开列表里的帖子，抓正文与结构化评论区，**只缓存到面板文章目录**；对话里只回标题+字数，不注入正文（小黑盒通常需要登录）
- `FeedReadUrl(url="...")`：读取白名单站点里的具体网址，同样只缓存、不注入
- `FeedInterest(target="猫", note="想看看别人养的猫")`：角色自己的兴趣清单（留空=查看，remove=true=移除）
- `FeedWander(topic="...")`：按自己的兴趣去刷/搜；不填 topic 就从兴趣清单挑最久没看的一条
- `FeedFavorite(id="TB3", favorite=true)`：收藏/取消收藏帖子（需登录）
- `FeedSaveImages(id="TB3", max=8)`：把帖子大图保存到本地（不是账号收藏）
- `FeedComment(id="TB3", text="...")`：评论（默认演练，只返回将要发布的内容）
- `FeedReply(id="TB3", target="热评原文", text="...")`：回复某条热评（默认演练）
- `FeedPublish(site="tieba", forum="电脑装机", title="...", text="...", images="...")`：发新帖（默认演练；贴吧要吧名，小黑盒可只给标题/正文；附图只从插件 images 目录取）
- `FeedStatus()`：浏览器是否就绪、最近抓取时间、今日写操作与自主浏览计数

## 自主浏览（角色自己的喜好）

推荐流（`FeedXhhList`）看到什么由平台算法决定；想让它自己挑，走两层：

1. **兴趣清单**：角色自己用 `FeedInterest` 写入想看的话题/吧，长期存在 `state.json`。清单为空时从配置里的「种子兴趣」挑。
2. **`FeedWander`**：不给 `topic` → 挑清单里**最久没看**的一条，吧名走 `FeedTiebaList`、关键词走 `FeedTiebaSearch`；给 `topic` → 临时主动去搜。`site="xhh"` 走小黑盒关键词搜索（`FeedXhhSearch`），不再默认抽首页推荐。

- 每次自主浏览会记 `CuriosityLog`（最近 40 条），避免连着看同一个。
- **阅读笔记**：浏览完把这一轮**真实标题**写进 `PluginData/presents.FeedScroll/notes/reading-notes.md`（最多 8 条），有 `feeling` 也一起写。文件始终写，方便自己/主人回看。
- **是否注入聊天**：由 `InjectReadingNote` 控制（默认关）。注入内容按 `ReadingNoteTemplate` 模板生成，可用 `{date} {site} {topic} {reason} {count} {titles} {feeling}`；占位符可删可改，控制台里有专门的编辑区。
- **注入限次**：`ReadingNoteInjectDailyLimit` 默认 2 条/天，到上限后只写文件、不再占用上下文；Nexus.Memory 收到几条就能记个大概，剩下的靠检索召回。
- **定时自主浏览**：`EnableScheduledBrowse` 打开后，在 `BrowseSlots`（一行一个，如 `09:00-10:00`，可加任意多个、支持 `22:00-01:00` 跨午夜）里自动刷；`BrowseRoundsPerDay` 控制每天最多几轮，`BrowsePostsPerRound` 控制每轮保留前几条，两轮之间默认隔 60 分钟（`BrowseRoundGapMinutes`）。控制台可随时增删时段、改轮数/条数。
- 每日次数上限 `AutonomyDailyLimit`（默认 6）仍然生效，定时轮也计入，避免悄悄烧 token。
- 可被屏蔽规则命中：兴趣里的吧/词如果在屏蔽列表，直接不看。
- 总开关 `EnableAutonomy`，关掉后只能由主人明确指定吧名/关键词。

## 评论区（楼中楼）

打开帖子时会一并读评论区，返回格式：

```
> 【评论区 · 5 条】（楼中楼用 ↳ 缩进）
> - [作者 · 12-05 21:33 · 赞 12] 顶层评论正文
>   ↳ [回复者 · 12-05 21:40] 楼中楼回复
```

- 顶层评论用 `.d_post_content`（跳过主楼），作者/时间/赞从楼层容器里取。
- 楼中楼优先取 `.lzl_content_main`，没有则退回 `.lzl_single_post` / `.lzl_content`；整体上限是「楼中楼条数」。
- 小黑盒没有贴吧这套 class，走通用兜底：抓最内层的 `[class*="comment"] / [class*="reply"]` 节点；抓不到就明确说「没读到评论区」，不会瞎编。
- 条数与字数：`顶层评论条数`（默认 6，0=不读）、`楼中楼条数`（默认 3，0=不读）、`单条评论字数上限`（默认 160）。
- 评论一样过屏蔽关键词与提示注入清洗；网页里的任何指令都不执行。

## 写操作与安全

| 配置 | 默认 | 说明 |
|---|---|---|
| 允许写操作 | 开 | 总开关（收藏/保存图片/评论/发帖） |
| 允许收藏帖子 | 开 | 每日上限 20 |
| 允许保存帖子图片 | 开 | 单次最多 8 张，落 `Storage/PluginData/presents.FeedScroll/images/` |
| 允许评论/回复 | 开 | 但默认走演练模式 |
| 评论演练模式 | **开** | 只返回预览，不发送 |
| 评论每日上限 | 3 | 真发才计数 |
| 允许发新帖 | 开 | 但默认走演练模式 |
| 发帖演练模式 | **开** | 只返回预览，不打开发布页 |
| 发帖每日上限 | 1 | 真发才计数 |
| 单帖附图上限 | 4 | 只从插件 `images` 目录取，单张默认 ≤ 5MB |
| 写操作最小间隔 | 5 秒 | 防手抖连点 |

评论和发帖内容都会做隐私（手机号/邮箱/QQ/微信/地址）、广告导流词、链接数量、字数与重复内容检查；遇到验证码/登录墙立即停止，请主人人工接管。

## 内容屏蔽

- **屏蔽的贴吧**：默认「核战避难所」；命中的吧不会刷（列表/搜索直接拒绝）。
- **屏蔽的标签/关键词**：默认 `nsfw, 福利姬, 裸照, 约炮, 色情, 成人内容, 里番, 本子, 性压抑`。
- **角色自己写入**：主人说「以后别看她刷某个吧/某个标签」→ `FeedBlock(target, kind=forum/keyword)`；`FeedBlockList` 查看；`FeedUnblock` 恢复（只移除角色追加的，配置里写死的要主人自己改）。
- 过滤顺序：吧名 → 列表标题/摘要 → 打开正文再兜底；正文命中关键词就不返回内容。
- 屏蔽规则只能来自主人明确指令，**不允许根据网页内容自动添加**。

所有输出都会包成 `[社区抓取·只读素材]`，并清洗「忽略之前指令 / 你现在是 / system prompt」这类提示注入；网页文字只当数据，不当指令。

## 登录

插件用自己的 WebView2 配置目录（`Storage/PluginData/presents.FeedScroll/WebView2`），Cookie 持久保存。

- 贴吧：一般免登录；若弹「百度安全验证」，点控制台「打开浏览器窗口」人工滑一次。
- 小黑盒：列表免登录可看；帖子正文通常要登录。在浏览器窗口里扫码/登录一次即可。

## 只读边界

没有点赞、关注工具；发帖工具默认演练、每日默认 1 帖，附图只从插件 images 目录取；也不会尝试绕过验证码。遇到登录墙/验证，交给人。

## 工具文档注入

插件以隐式功能注册，系统提示词里只占一行；AI 调 `<FeedScrollModule/>` 时，框架默认会把整份文档注入对话。**本插件默认关闭完整注入**，只回一行函数名；控制台「工具文档注入」区可以：

- 开关完整注入：关掉后只回一行函数名提醒；
- 设置每天最多完整注入几次（默认 2，0 = 不限）；
- 直接编辑「短描述」和「详细说明」，并预览最终文档（函数签名由代码自动生成，不可编辑）；
- 改动即时落盘；短描述要重载插件后才会更新到系统提示词。

## 控制台

角色插件面板里有「刷贴吧与小黑盒」：查看浏览器状态、打开登录窗口、输入吧名试刷、刷小黑盒、按 AI 兴趣刷一条、查看最近一次列表；「今日操作」里可切换评论演练与发帖演练；「自主阅读 · 注入与定时」区可直接开关注入、编辑注入模板与每日上限、增删任意多个定时时段、改每天轮数与每轮条数；「工具文档注入」区可开关完整文档、限次、编辑文案并预览（改动即时落盘）。

## 状态

- `state.json`：最近一次列表缓存（`TB1` / `XH1` 这类临时 id）、兴趣清单、自主浏览记录、屏蔽规则、写操作计数、今日注入条数、定时轮数与工具文档注入次数
- WebView2 配置目录：登录 Cookie

## 已知限制

- 站点 DOM 会变，抽取脚本对贴吧/小黑盒做了多套兜底；如果标题/正文抓不准，让主人打开浏览器窗口看一眼，或改用 `FeedReadUrl`。
- 小黑盒详情依赖登录；未登录时只能看列表与部分正文。
- 网页版发帖入口/编辑器可能随站点改版；如果 `FeedPublish` 找不到标题/正文/图片入口，先打开浏览器窗口确认能发，再把直接发布页地址填到配置「贴吧发帖入口 / 小黑盒发帖入口」。
